# David de la Cruz - Portfolio Website

Modern, dark-themed portfolio showcasing AI engineering projects and skills.

## 🚀 Quick Start

### Option 1: GitHub Pages (Recommended - FREE)

1. Create a new GitHub repository named `portfolio` or `your-username.github.io`
2. Upload all files from the `portfolio` folder
3. Go to Settings → Pages
4. Select "Deploy from main branch"
5. Your site will be live at: `https://your-username.github.io/portfolio`

### Option 2: Local Testing

1. Open `index.html` in your browser
2. That's it! No build process needed.

## 🎨 Customization

### Update Contact Links

Find this section in `index.html` (around line 400):

```html
<a href="mailto:davidcruz.eu@gmail.com" class="contact-link">
<a href="https://linkedin.com/in/davidlacruz" target="_blank" class="contact-link">
<a href="https://github.com/daviddelacruz" target="_blank" class="contact-link">
```

Update with your actual GitHub username if different.

### Add More Projects

Copy this block and modify:

```html
<div class="project-card">
    <img src="your-project.jpg" alt="Project Name" class="project-image">
    <div class="project-content">
        <h3>Project Name</h3>
        <p class="tech-stack">Tech • Stack • Here</p>
        <p>Project description...</p>
        <div class="project-links">
            <a href="URL" target="_blank" class="project-link">View Live →</a>
        </div>
    </div>
</div>
```

## 🌐 Custom Domain (Optional)

1. Buy a domain (e.g., davidcruz.dev)
2. In GitHub Pages settings, add your custom domain
3. Update DNS records at your domain provider:
   - Add CNAME record pointing to `your-username.github.io`
